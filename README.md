# Лабораторная работа №2 — Фундаментальные алгоритмы

- `task01.c` — обработка строк: длина, разворот, изменение регистра, перестановка символов и объединение строк.
- `task02.c` — сортировка сотрудников по зарплате, фамилии, имени и id.
- `task03.c` — поиск всех вхождений подстроки в файлах с указанием строки и столбца.
- `task04.c` — выбор файлов для резервного копирования с максимальной важностью при ограниченной вместимости.
- `task05.c` — форматированный вывод с римскими числами, цекендорфовой записью, переводом оснований и дампами памяти.
- `task06.c` — форматированный ввод римских чисел, цекендорфовой записи и чисел в разных основаниях.
- `task07.c` — поиск всех самых длинных векторов по трём нормам.
- `task08.c` — сложение длинных неотрицательных чисел в основаниях от 2 до 36.
- `task09.c` — проверка конечности записи дроби в заданном основании.
- `task10.c` — переразложение многочлена по степеням `(x - a)`.
